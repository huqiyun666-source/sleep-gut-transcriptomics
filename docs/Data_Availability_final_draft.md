# Data Availability statement — final draft

## A. BEFORE_REPOSITORY_PUBLICATION

The public datasets analysed in this study are available under GSE289089 / PRJNA1221288, PRJNA1167170, and PRJNA862187. A curated code and processed-results package has been prepared for public archiving. The repository URL and persistent DOI are pending and will be inserted after deposition; raw sequencing reads, reference resources, and large intermediate objects are not redistributed in the package.
